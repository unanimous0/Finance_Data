# 분봉 데이터 수집 계획

> **작성일**: 2026-03-04
> **목적**: KOSPI200, KOSDAQ150, 국내형 ETF에 대한 1분봉 데이터 수집 체계 구축

---

## 1. 현재 구조 (인포맥스 API)

| 데이터 | API | 주기 | 비고 |
|--------|-----|------|------|
| 일봉 OHLCV | `/api/stock/hist` | 매일 | 전 종목 (3,794개) |
| 시가총액 | `/api/stock/info` | 매일 | close_price × listed_shares |
| 투자자 수급 | `/api/stock/investor` | 매일 | KOSPI+KOSDAQ (2,719개), ETF 제외 |
| 종목 마스터 | `/api/stock/code` | 매일 | 신규 상장 반영 |
| 상장폐지 | `/api/stock/expired` | 매일 | is_active=FALSE 처리 |
| 유동주식수 | FnGuide 크롤링 | 월 1~2회 | KOSPI+KOSDAQ만 |

- **요금제**: Lite (월 10만원, 60건/분, 0.2GB/일)
- **소요시간**: ~2시간 (rate limit 병목)

## 2. 분봉 데이터 수집 방법 조사 결과

### 인포맥스 API — 분봉 미지원

인포맥스 API에는 분봉 엔드포인트가 없음. 가장 가까운 대안은 틱 데이터(`/api/stock/tick`)이나:
- 과거 조회: **최대 7일**
- 데이터량: 850종목 틱 수집 시 하루 ~800MB → Lite(0.2GB) 초과, Pro(1.0GB)도 빠듯
- 1분봉으로 직접 집계해야 함

### 증권사 API 비교

| 증권사 | 1분봉 과거 기간 | API 방식 | Linux 지원 | 비용 | 요청 제한 |
|--------|---------------|---------|-----------|------|----------|
| **LS증권** | **~1년** | **REST (HTTP)** | **가능** | 무료 (계좌) | 추정 300~600건/분 |
| 대신증권 | ~2년 (18.5만건) | COM (Windows) | 불가 | 무료 (계좌) | 240건/분 |
| 키움증권 | ~160일 | OCX(Win) / REST | REST는 가능 | 무료 (계좌) | 300건/분 (1초5회) |
| 한국투자증권 | **당일만** | REST | 가능 | 무료 (계좌) | - |

### 결론: LS증권 REST API 채택

- Linux 서버에서 직접 동작 (REST)
- 1년치 과거 데이터로 초기 백필 가능
- 매일 수집하면 이후로 계속 축적
- 무료

## 7. 참고: 증권사별 상세 비교

### LS증권 (채택)
- **공식 사이트**: https://openapi.ls-sec.co.kr
- **API 방식**: REST (HTTP) — Linux/Mac 가능
- **분봉 조회**: t8412 TR (주식분봉차트조회)
- **과거 데이터**: ~1년
- **비용**: 무료 (계좌 필요)
- **GitHub 샘플**: https://github.com/teranum/ls-openapi-samples

### 대신증권 (미채택 — Windows 전용)
- **API**: CYBOS Plus (COM 방식)
- **분봉**: 1분봉 ~18.5만건(~2년), 5분봉 ~9만건(~5년)
- **장점**: 과거 데이터 최대, 사용성 좋음
- **단점**: Windows만 지원, Linux 서버에서 직접 사용 불가
- **참고**: https://github.com/gyusu/Creon-Datareader

### 한국투자증권 (미채택 — 당일만)
- **API**: REST — Linux 가능
- **분봉**: 1분봉, **당일만** 조회 가능
- **단점**: 과거 백필 불가, 하루라도 빠지면 복구 불가
- **참고**: https://apiportal.koreainvestment.com

### 키움증권 (미채택)
- **API**: OCX (Windows) / REST (최근 출시)
- **분봉**: ~160일
- **참고**: https://openapi.kiwoom.com
